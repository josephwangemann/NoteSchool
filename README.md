# Chord & Scale Reference 🎸

A minimalist music theory reference tool

## Features

- Scale & Chord charts for Key
- Random note generator for memorizing notes on the fretboard
- Pitch reference for tuning

## Quick Start

Use Node.js 22.13 or newer.

```bash
npm install
npm run ios
npm run android
```

## Tech Stack

- React Native
- Expo
- TypeScript
